What this experiment measures

Independent layout, shared drawing. CanvasKit uses SkParagraph. Parley runs in WebAssembly and sends positioned glyphs to the same Skia renderer. Both use identical Noto font files.

Editing before optimization. A textarea captures native input. The canvases draw text and selections. Paragraphs are cached; layout stays on the main thread for this first comparison.

A prototype, not an accessibility claim. Plain text is available through the input element. Rich document semantics, native IME behavior, and assistive technology still need hands-on review.

Layout measurements

Warm paragraph rebuilds at the current width. Drawing and font loading are excluded. Adapter time includes geometry extraction and, for Parley, JSON transfer and validation.
